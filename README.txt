Финансовый пульт для iPhone

1. Опубликуйте содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте HTTPS-адрес на iPhone в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Данные сохраняются локально на устройстве, не синхронизируются между устройствами. Регулярно экспортируйте резервную копию JSON.
5. Перед переносом старых отметок в старой версии нажмите «Экспорт данных», затем в новой импортируйте JSON через «Настройки».
6. Установленная и открытая в Safari версии могут иметь разные хранилища: импортируйте копию в установленное приложение.
